# Build Project

This workflow installs the required dependencies and builds the Next.js project.

## Step 1: Install Dependencies
Run the following command to install all NPM dependencies:
```bash
npm install
```

## Step 2: Build Project
Run the following command to compile and build the production-ready application:
```bash
npm run build
```
