# Preview Project

This workflow starts the Next.js development server to preview the application locally.

## Step 1: Start Preview Server
Run the following command to start the development server:
```bash
npm run dev
```

The application will typically be available at `http://localhost:3000`. You can preview the web app by opening this URL in a browser.
